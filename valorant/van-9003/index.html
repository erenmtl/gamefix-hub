Valorant VAN 9003 Hatası Nasıl Çözülür? (UEFI Secure Boot)

Hata Kodu
VAN 9003
Çözüm Planı
4 Doğrulanmış Adım
Test Edilen Sistem
Windows 10 / 11 (23H2 & 24H2)
Son Güncelleme
17.11.2026
Bu hata ne anlama geliyor?

Valorant VAN 9003 ('This build of Vanguard requires secure boot to be enabled in order to play'), Riot Vanguard çekirdek sürücüsünün (vgk.sys) Windows 11 önyükleme zincirinde UEFI Güvenli Önyükleme (Secure Boot) doğrulamasını aktif olarak bulamadığını gösteren hata kodudur. Oyuncuların valorant van 9003 veya bitişik yazımla van9003 olarak arattığı bu uyarı, anakart BIOS ayarlarında CSM kapatılıp Secure Boot anahtarları etkinleştirilerek çözülür.

Hızlı Çözüm (İlk Adım) Tüm adımlara in (4 adım) ↓

En Olası İlk Adım: BIOS'ta CSM Kapatıp Secure Boot Anahtarlarını Yükleyin

BIOS > Boot menüsünden CSM (Compatibility Support Module) ayarını Disabled yapın ve Secure Boot > Key Management altından 'Install Default Secure Boot Keys / Restore Factory Keys' seçeneğini onaylayın.

powershell -Command "Confirm-SecureBootUEFI"

Bu Hatanın Nedenleri

  • Anakart BIOS ayarlarında CSM (Compatibility Support Module) özelliğinin açık (Enabled) bırakılması.
  • BIOS içinde Secure Boot seçeneği 'Enabled' görünmesine rağmen Platform Key (PK) fabrika anahtarlarının yüklenmemiş olması nedeniyle durumun 'Not Active' kalması.
  • Disk bölümleme tablosunun UEFI için gereken GPT yerine eski MBR (Legacy) formatında olması.
Hangisi senin durumun? (Sistemine Göre Seç)

ASUS ve MSI BIOS Üzerinden Secure Boot Aktifleştirme

ASUS anakartlarda BIOS > Boot > CSM > Launch CSM: Disabled yapın; ardından Secure Boot > OS Type: Windows UEFI Mode seçip Key Management > Install Default Secure Boot Keys onaylayın. MSI anakartlarda Settings > Advanced > Windows OS Configuration > BIOS UEFI/CSM Mode: UEFI seçip Secure Boot > Enroll all Factory Default keys adımını uygulayın.

Gigabyte ve ASRock BIOS Üzerinden Secure Boot Aktifleştirme

Gigabyte anakartlarda BIOS > Boot > CSM Support: Disabled yapın; Secure Boot menüsünde durum 'Not Active' ise Secure Boot Mode'u Custom yapıp 'Restore Factory Keys' seçin. ASRock anakartlarda Boot > CSM: Disabled yapıp Security > Secure Boot > Install default Secure Boot keys seçeneğine tıklayın.

Adım Adım Çözüm

İlerleme: 0/4 adım
Geri yükleme noktası oluşturun: Sistem veya servis ayarlarını değiştirmeden önce Windows'ta bir Sistem Geri Yükleme Noktası (Checkpoint-Computer -Description "OyunCoz_Yedek") oluşturmanız önerilir.
Adım 1

Mevcut Güvenli Önyükleme (Secure Boot) ve BIOS Modunu Doğrulayın

Klavyeden Win + R tuşlarına basıp msinfo32 yazarak Sistem Bilgisi penceresini açın. 'BIOS Modu' satırının UEFI olduğundan ve 'Güvenli Önyükleme Durumu (Secure Boot State)' satırının Açık/Kapalı durumunu kontrol edin. Ayrıca tpm.msc komutuyla TPM 2.0 hazırlık durumunu doğrulayın.

Komut İstemi / PowerShell Yönetici olarak çalıştırın
powershell -Command "Confirm-SecureBootUEFI"
Komut Güvenlik Bilgisi:
Ne yapar? Windows PowerShell üzerinden anakartta UEFI Secure Boot özelliğinin aktif (True) olup olmadığını salt-okunur olarak sorgular.
Risk: Salt-okunur bir doğrulama komutudur; sistem veya BIOS ayarlarında değişiklik yapmaz.
Geri alma: Herhangi bir sistem değişikliği yapmadığı için geri alma işlemi gerektirmez.
Tamamlandı
Adım 2

Anakart BIOS Menüsünden CSM Kapatma ve Secure Boot Aktifleştirme

Bilgisayarı yeniden başlatırken DEL veya F2 tuşuna basarak BIOS'a girin. Boot menüsünden CSM (Compatibility Support Module) ayarını Disabled yapın, OS Type / Secure Boot Mode ayarını Windows UEFI Mode veya Standard konumuna getirin ve Key Management altından varsayılan fabrika anahtarlarını (Install Default Secure Boot Keys / Restore Factory Keys) yükleyin.

ASUS Anakart BIOS Adımları

BIOS > Boot > CSM (Compatibility Support Module) > Launch CSM: Disabled yapın. Ardından Boot > Secure Boot > OS Type: Windows UEFI Mode seçin ve Key Management > Install Default Secure Boot Keys seçeneğini onaylayıp F10 ile kaydedin.

MSI Anakart BIOS Adımları

BIOS > Settings > Advanced > Windows OS Configuration > BIOS UEFI/CSM Mode: UEFI seçin. Secure Boot menüsüne girip Secure BootMode: Custom > Enroll all Factory Default keys onaylayın ve tekrar Standard moda alıp F10 ile kaydedin.

Gigabyte Anakart BIOS Adımları

BIOS > Boot > CSM Support: Disabled yapın. Açılan Secure Boot menüsünde Secure Boot: Enabled seçin. Durum 'Not Active' görünüyorsa Secure Boot Mode'u Custom yapıp 'Restore Factory Keys' seçin ve F10 ile kaydedin.

ASRock Anakart BIOS Adımları

BIOS > Boot > CSM (Compatibility Support Module): Disabled yapın. Security > Secure Boot menüsüne geçip 'Install default Secure Boot keys' seçeneğine tıklayın ve Secure Boot: Enabled yaparak F10 ile kaydedin.

Tamamlandı
Adım 3

AMD fTPM ve Intel PTT (TPM 2.0) Modülünü Etkinleştirin

AMD Ryzen işlemcili anakartlarda Advanced > AMD fTPM Configuration > AMD fTPM Switch ayarını Enabled yapın. Intel işlemcili anakartlarda Settings > Security > Trusted Computing > Intel Platform Trust Technology (PTT) ayarını Enabled konumuna getirin ve F10 ile kaydedip çıkın.

Tamamlandı
Adım 4

Riot Vanguard (vgc) Hizmetini Otomatik Başlatın

Windows açıldığında Hizmetler (services.msc) penceresinden 'vgc' hizmetini bulun, Başlangıç Türünü 'Otomatik' yapıp hizmeti başlatın. Komut İstemi'ni (CMD) Yönetici olarak açıp aşağıdaki komutu çalıştırarak servisin çalıştığını doğrulayın.

Komut İstemi / PowerShell Yönetici olarak çalıştırın
sc config vgc start= auto && net start vgc
Komut Güvenlik Bilgisi:
Ne yapar? Riot Vanguard kullanıcı modu hizmetini (vgc) Otomatik başlangıç türüne alır ve servisi başlatır.
Risk: Standart Windows hizmet yapılandırma komutudur; sistem dosyalarını silmez.
Geri alma: Hizmetler (services.msc) penceresinden vgc hizmetini tekrar Elle (Manual) durumuna getirebilirsiniz.
Tamamlandı

İşe Yaramazsa Ne Yapmalısınız?

msinfo32 ekranında BIOS Modu 'Eski (Legacy)' görünüyorsa diskiniz MBR formatındadır; CSM kapatmadan önce diskin GPT formatında olması gerekir. Ayrıca Windows Güvenliği > Cihaz Güvenliği > Çekirdek Yalıtımı altındaki Bellek Bütünlüğü ayarını kontrol edin.

Sıkça Sorulan Sorular (SSS)

BIOS'ta Secure Boot Enabled görünmesine rağmen Valorant neden hala VAN 9003 (van9003) veriyor?

ASUS, MSI, Gigabyte ve ASRock anakartlarda Secure Boot seçeneği Enabled olsa bile Platform Key (PK) anahtarları yüklenmemişse Secure Boot durumu 'Not Active' kalır. BIOS > Secure Boot > Key Management menüsünden 'Install Default Secure Boot Keys' (veya Restore Factory Keys) işlemini uyguladığınızda Secure Boot aktif hale gelir.

valorant van 9003 hatası Windows 11'de neden ortaya çıkar?

Windows 11 23H2 ve 24H2 sürümlerinde Riot Vanguard çekirdek sürücüsü (vgk.sys), önyükleme zincirinin güvenliğini doğrulamak için UEFI Secure Boot ve TPM 2.0 modüllerinin donanımsal olarak 'Aktif (Active)' durumda çalışmasını zorunlu tutar.

BIOS ayarlarını değiştirmeden önce hangi önlemi almalıyım?

İşlemlere başlamadan önce msinfo32 üzerinden BIOS Modunun UEFI olduğundan emin olun ve PowerShell'de Checkpoint-Computer -Description "OyunCoz_Yedek" komutuyla bir Sistem Geri Yükleme Noktası oluşturun.
