Bu hata ne anlama geliyor?

Minecraft Launcher'da 'Oyun beklenmedik şekilde çöktü — Çıkış Kodu: 1 (Exit Code: 1)' hatası, Java Sanal Makinesi'nin (JVM) başlatma sırasında uyumsuz bir Forge/Fabric modu, bozuk yapılandırma dosyası veya yanlış Java sürümü nedeniyle sonlandığını gösterir.

Hızlı Çözüm (İlk Adım) Tüm adımlara in (3 adım) ↓

En Olası İlk Adım: Uyumsuz Modları Çıkarın ve Yerleşik Java 21 Yolunu Sıfırlayın

%appdata%\.minecraft\mods klasöründeki uyumsuz .jar modlarını kontrol edin ve Minecraft Launcher > Yüklemeler > Düzenle altından Java Yürütülebilir Dosyası yolunu varsayılana sıfırlayın.

java -version

Bu Hatanın Nedenleri

  • Minecraft 1.20.5 ve 1.21+ sürümleri Java 21 gerektirirken sistemde eski Java 8 veya Java 17 yolunun seçili olması.
  • %appdata%\.minecraft\mods klasöründe oyun sürümüyle uyumsuz bir .jar mod dosyasının bulunması.
  • JVM Başlatma Argümanlarında (-Xmx) sistemde bulunandan fazla RAM ayrılması.

Adım Adım Çözüm

İlerleme: 0/3 adım
Geri yükleme noktası oluşturun: Sistem veya servis ayarlarını değiştirmeden önce Windows'ta bir Sistem Geri Yükleme Noktası (Checkpoint-Computer -Description "OyunCoz_Yedek") oluşturmanız önerilir.
Adım 1

mods Klasöründeki Uyumsuz Modları ve latest.log Kaydını Kontrol Edin

Win + R tuşlarına basıp %appdata%\.minecraft\logs\latest.log dosyasını açarak çökme satırını kontrol edin; uyumsuz modları mods klasöründen geçici olarak çıkarın.

Komut İstemi / PowerShell Yönetici olarak çalıştırın
java -version
Komut Güvenlik Bilgisi:
Ne yapar? Sistemde kurulu olan varsayılan Java sürümünü ve 64-bit mimarisini salt-okunur olarak gösterir.
Risk: Salt-okunur sorgulama komutudur; hiçbir sistem ayarını değiştirmez.
Geri alma: Geri alma işlemi gerektirmez.
Tamamlandı
Adım 2

Minecraft Yüklemeler Ayarından Java Yürütülebilir Dosya Yolunu Sıfırlayın

Minecraft Launcher > Yüklemeler (Installations) > Profilin yanındaki 3 nokta > Düzenle > Daha Fazla Seçenek altındaki 'Java Yürütülebilir Dosyası' kutusunu sıfırlayarak yerleşik Java 21'i kullanmasını sağlayın.

Tamamlandı
Adım 3

JVM RAM Argümanını (-Xmx) Dengeli Seviyeye Ayarlayın

16 GB RAM'li bir bilgisayarda JVM Argümanları satırındaki -Xmx değerini -Xmx4G veya modlu paketlerde -Xmx6G olarak ayarlayıp kaydedin.

Tamamlandı

İşe Yaramazsa Ne Yapmalısınız?

Windows Grafik Ayarları üzerinden javaw.exe dosyasını Yüksek Performanslı harici ekran kartınıza (NVIDIA / AMD) atayın ve ekran kartı OpenGL sürücünüzü güncelleyin.

Sıkça Sorulan Sorular (SSS)

Minecraft Exit Code 1 hatası neden olur?

En yaygın sebebi Forge/Fabric mods klasöründeki uyumsuz bir .jar mod dosyası veya Minecraft 1.20.5+ sürümünde Java 21 yerine eski Java sürümünün seçili olmasıdır.

mods klasöründeki modları taşımak dünyalarımı (saves) siler mi?

Dünyalarınız saves klasöründe yer alır; ancak modlu bloklar içeren bir dünyayı modları çıkardıktan sonra açmadan önce saves klasörünüzün yedeğini almanız önerilir.
