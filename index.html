Hızlı Sistem Onarım Komutları

                    
Yönetici CMD / PowerShell için temel komutlar

                  

                

              


              

                

                  

                    1. Bozuk Sistem Dosyalarını Onar
                    Yönetici CMD
                  

                  sfc /scannow
                


                

                  

                    2. Ağ & Soket Yığınını Sıfırla
                    Ping / VAN 185
                  

                  netsh winsock reset && ipconfig /flushdns
                


                

                  

                    3. DirectX Gölgelendirici Temizliği
                    DX12 / Stutter
                  

                  cleanmgr /d C
