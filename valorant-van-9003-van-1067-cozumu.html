Valorant VAN 9003, VAN 1067, TPM 2.0 ve Secure Boot Kesin Çözüm Rehberi

Windows 11 23H2 ve 24H2 güncellemeleri sonrasında Riot Vanguard çekirdek (kernel) sürücüsü, anakartınızda UEFI Secure Boot (Güvenli Önyükleme) ve TPM 2.0 (fTPM / PTT) modüllerinin yalnızca açık olmasını değil, donanımsal olarak 'Aktif (Active)' durumda çalışmasını zorunlu tutar. Aşağıdaki adım adım rehber ile VAN 9003, VAN 1067 ve VAL 62 hatalarını 3 dakikada kalıcı olarak çözebilirsiniz.

🛠️ Adım Adım Kesin Çözüm Rehberi

Adım 1

Mevcut Güvenli Önyükleme ve BIOS Modunu Doğrulayın

Klavyeden Win + R tuşlarına basıp msinfo32 yazarak Sistem Bilgisi penceresini açın. 'BIOS Modu' satırının UEFI olduğundan ve 'Güvenli Önyükleme Durumu (Secure Boot State)' satırının Açık/Kapalı durumunu kontrol edin. Ayrıca tpm.msc komutuyla TPM 2.0 hazırlık durumunu doğrulayın.

Adım 2

BIOS Üzerinden CSM Kapatma ve UEFI Secure Boot Aktifleştirme

Bilgisayarı yeniden başlatırken DEL veya F2 tuşuna basarak BIOS'a girin. Boot menüsünden CSM (Compatibility Support Module) ayarını Disabled yapın. Secure Boot menüsüne girip OS Type / Secure Boot Mode ayarını 'Windows UEFI Mode' veya 'Standard' yapın. Eğer msinfo32'de hala Kapalı görünüyorsa 'Key Management' altından 'Install Default Secure Boot Keys' (Fabrika Anahtarlarını Yükle) seçeneğini onaylayın.

Adım 3

AMD fTPM ve Intel PTT (TPM 2.0) Modülünü Açın

AMD Ryzen işlemcili anakartlarda Advanced > AMD fTPM Configuration > AMD fTPM Switch ayarını Enabled yapın. Intel işlemcili anakartlarda Settings > Security > Trusted Computing > Intel Platform Trust Technology (PTT) ayarını Enabled konumuna getirin ve F10 ile kaydedip çıkın.

Adım 4

Riot Vanguard (vgc) Hizmetini Otomatik Başlatın ve Onarın

Windows açıldığında Hizmetler (services.msc) penceresinden 'vgc' hizmetini bulun, Başlangıç Türünü 'Otomatik' yapıp hizmeti başlatın. Komut İstemi'ni (CMD) Yönetici olarak açıp aşağıdaki doğrulama komutlarını çalıştırın.

💻 Hızlı Onarım ve Doğrulama Komutları (CMD / PowerShell)

Yönetici Olarak Çalıştırın

İşlemlere başlamadan önce Sistem Geri Yükleme Noktası oluşturmak için: Checkpoint-Computer -Description "OyunCoz_Yedek"

❓ Sıkça Sorulan Sorular (SSS)

❓ BIOS'ta Secure Boot Enabled görünmesine rağmen Valorant neden hala VAN 9003 veriyor?

ASUS ve Gigabyte anakartlarda Secure Boot seçeneği Enabled olsa bile Platform Key (PK) anahtarları yüklenmemişse Secure Boot durumu 'Not Active' kalır. BIOS > Secure Boot > Key Management menüsünden 'Install Default Secure Boot Keys' (veya Restore Factory Keys) işlemini uyguladığınızda sorun anında çözülür.

❓ Valorant VAN 1067 hatası neden kaynaklanır?

VAN 1067 hatası TPM 2.0 servisinin yanıt vermemesi, vgc hizmetinin durması veya Discord/RivaTuner gibi 3. parti ekran katmanı (overlay) yazılımlarının Vanguard ile çakışmasından kaynaklanır. vgc hizmetini Otomatik yapıp bilgisayarı yeniden başlatmak %95 oranında sorunu çözer.

❓ Valorant paket kaybı (Packet Loss) ve mikro takılma (stutter) nasıl giderilir?

Oyun içi Genel ayarlarından 'Ağ Arabelleği' değerini Asgari'den Orta'ya çekin, Faresiz Ham Giriş (RawInputBuffer) özelliğini Açık yapın ve CMD'de ipconfig /flushdns && netsh int ip reset komutlarını çalıştırın.
