🔍 Bu Hata Neden Olur? (VAN 9003 Teknik Nedeni)

Valorant VAN 9003 hatası, Riot Vanguard çekirdek (kernel-level) güvenlik sürücüsünün Windows 11 işletim sisteminde UEFI Güvenli Önyükleme (Secure Boot) ve TPM 2.0 modüllerinin aktif olarak çalışmasını zorunlu tutmasından kaynaklanır. Bilgisayarınızın BIOS/UEFI ayarlarında CSM (Compatibility Support Module) açıksa, Secure Boot 'Enabled' görünse bile 'Not Active' (Etkin Değil) durumunda kalır ve Vanguard oyunu başlatmayı reddeder.

⚠️ Güvenlik Notu: Sistem komutlarını (CMD) veya BIOS/Kayıt Defteri değişikliklerini uygulamadan önce Windows arama çubuğuna Geri yükleme noktası oluştur yazarak bir Sistem Geri Yükleme Noktası almanız önerilir.

Çözüm Adımı 1 VAN 9003

Adım 1: msinfo32 ve TPM Durumunu Doğrulama

Öncelikle Windows üzerinden BIOS modunuzun UEFI olup olmadığını ve Güvenli Önyükleme Durumunun 'Açık' görünüp görünmediğini kontrol edin.

💻 Sistem / Komut Satırı: 
msinfo32

ℹ️ Sistem Bilgisi penceresini açar. 'BIOS Modu: UEFI' ve 'Güvenli Önyükleme Durumu: Açık' satırlarını kontrol edin.

Çözüm Adımı 2 VAN 9003

Adım 2: Gelişmiş Başlangıç ile doğrudan UEFI BIOS'a Geçiş

Bilgisayar açılırken DEL/F2 tuşunu yakalayamıyorsanız, Yönetici Komut İstemi (CMD) üzerinden aşağıdaki güvenli komutla doğrudan BIOS ekranına yeniden başlatabilirsiniz.

💻 Sistem / Komut Satırı: 
shutdown /r /fw /t 0

ℹ️ Ne yapar: Bilgisayarı doğrudan anakart UEFI BIOS arayüzünde yeniden başlatır. Risk: Açık belgelerinizi kaydetmeden çalıştırmayın.

Çözüm Adımı 3 VAN 9003

Adım 3: BIOS'ta CSM Kapatma ve Secure Boot Key Management

ASUS, MSI, Gigabyte veya ASRock anakartınızda Boot sekmesine gidin: CSM Support ayarını 'Disabled' yapın, OS Type ayarını 'Windows UEFI Mode' seçin ve Secure Boot Mode'u 'Custom'dan 'Standard'a alıp Fabrika Anahtarlarını (Install Default Secure Boot Keys) yükleyin.

💻 Sistem / Komut Satırı: 
powershell -Command "Confirm-SecureBootUEFI"

ℹ️ Windows açıldığında PowerShell'de 'True' döndürüyorsa Secure Boot başarıyla etkinleşmiştir.

Çözüm Adımı 4 VAN 9003

Adım 4: Riot Vanguard (vgc) Servisini Otomatik Başlatma

BIOS ayarlarından sonra Vanguard kullanıcı modu servisinin (vgc) kapalı kalmasını önlemek için hizmeti otomatik moda alıp başlatın.

💻 Sistem / Komut Satırı: 
sc config vgc start= demand & net start vgc

ℹ️ Ne yapar: Riot Vanguard (vgc) servisini yapılandırır ve başlatır. Geri alma: Hizmetler (services.msc) üzerinden manuel moda alınabilir.

❓ Sıkça Sorulan Sorular (Valorant VAN 9003)

S: BIOS'ta Secure Boot Enabled görünüyor ama Windows'ta Kapalı yazıyor, neden?

Anakartlarda Secure Boot 'Enabled' olsa bile Platform Key (PK) anahtarları yüklenmemişse 'Not Active' kalır. BIOS'ta Secure Boot Mode'u 'Custom' yapıp 'Restore Factory Keys' seçeneğini onaylayarak 'Standard' moda geri alın.

S: Diskim MBR formatındaysa CSM kapatınca Windows açılır mı?

MBR disklerde CSM kapatılırsa sistem diski göremez. Önce Windows'ta Yönetici CMD üzerinden 'mbr2gpt /validate /allowFullOS' ve 'mbr2gpt /convert /allowFullOS' komutuyla veri kaybetmeden GPT'ye dönüştürmeniz gerekir.

S: Valorant VAN 9003 Windows 10'da da çıkar mı?

Genellikle Windows 11'de zorunludur ancak VBS (Sanallaştırma Tabanlı Güvenlik) açık olan güncel Windows 10 sistemlerde de Vanguard TPM ve Secure Boot doğrulaması isteyebilir.
