Minecraft Çıkış Kodu: 1 (Exit Code 1), Exit Code -1073740791 ve GLFW Error 65542 Çözümü

Minecraft Java Edition'da 'Oyna' butonuna bastıktan hemen sonra alınan 'Exit Code: 1' (Çıkış Kodu 1) hatası uyumsuz modlar (.jar) veya yanlış Java sürümünden; 'GLFW Error 65542' ise Windows'un harici ekran kartı yerine bozuk dahili OpenGL sürücüsünü kullanmasından kaynaklanır.

🛠️ Adım Adım Kesin Çözüm Rehberi

Adım 1

Minecraft Sürümünüze Uygun Java (JDK 17 / JDK 21) Sürümünü Seçin

Minecraft 1.20.5 ve 1.21+ sürümleri Java 21 (JDK 21), 1.18 - 1.20.4 arası sürümler Java 17, 1.16.5 ve altı ise Java 8 gerektirir. Minecraft Launcher > Yüklemeler > Düzenle > Daha Fazla Seçenek altındaki 'Java Yürütülebilir Dosyası' yolunu varsayılana sıfırlayın.

Adım 2

Forge / Fabric Uyumsuz Mod (.jar) Çakışmasını Ayıklayın

Win + R tuşlarına basıp %appdata%\.minecraft\mods klasörünü açın. Oyun sürümünüzle uyuşmayan OptiFine veya eski modları başka bir klasöre taşıyıp oyunu test edin. Ayrıca logs\latest.log dosyasını OyunÇöz Crash Log Analizcisine sürükleyerek çökme yaratan modu saniyede bulabilirsiniz.

Adım 3

GLFW Error 65542 İçin javaw.exe'yi Yüksek Performanslı GPU'ya Atayın

Windows Ayarları > Sistem > Ekran > Grafikler menüsüne girin. 'Masaüstü uygulaması ekle' diyerek C:\Program Files (x86)\Minecraft Launcher\runtime\java-runtime-delta\windows-x64\java-runtime-delta\bin\javaw.exe dosyasını seçin ve 'Yüksek Performans (NVIDIA / AMD)' olarak ayarlayın.

Adım 4

JVM RAM Argümanlarını (-Xmx) Dengeli Yapılandırın

Modlu Minecraft için 4 GB ile 8 GB arası RAM (-Xmx6G) idealdir. Bilgisayarınızdaki tüm RAM'i Minecraft'a vermek Windows'un çökmesine (Exit Code -1073740791) yol açar.

❓ Sıkça Sorulan Sorular (SSS)

❓ Minecraft Exit Code 1 hatasını modları silmeden nasıl çözerim?

.minecraft/logs/latest.log dosyasını OyunÇöz ana sayfasındaki 'Crash Log Sürükle-Bırak' kutusuna bırakın. Sistem hangi modun Exception fırlattığını otomatik tespit eder; sadece o bozuk modu güncelleyerek diğer modlarınızı koruyabilirsiniz.

❓ GLFW Error 65542 WGL OpenGL hatası nasıl düzeltilir?

Windows Update bazen ekran kartının OpenGL ICD sürücüsünü eksik kurar. DDU ile sürücüyü temizleyip NVIDIA veya AMD'nin resmi sitesinden güncel WHQL sürücüyü kurmak OpenGL desteğini geri getirir.
